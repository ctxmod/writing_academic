# Broad Scan

Broad scanning establishes baseline understanding of a topic before focused investigation. The goal is mapping the landscape—identifying key sources, concepts, debates, and gaps—rather than deep analysis.

## Scanning Procedure

### Phase 1: Initial Sweep

1. **Formulate broad queries** covering the topic's primary dimensions
2. **Execute queries in parallel** across multiple source types
3. **Capture results** without deep evaluation (title, source, brief relevance note)
4. **Deduplicate** findings that appear across multiple queries

### Phase 2: Landscape Mapping

From initial results, identify:

- **Key sources**: Most-cited or most-relevant outputs
- **Key contributors**: Authors, organizations, or projects appearing repeatedly
- **Key concepts**: Terminology and frameworks used across sources
- **Key debates**: Areas where sources disagree
- **Key gaps**: Questions no sources address

### Phase 3: Scope Refinement

Use the landscape map to refine investigation scope:

1. **Prioritize**: Which areas require deep investigation?
2. **Deprioritize**: Which areas are well-established and need only summary treatment?
3. **Identify follow-up queries**: What specific questions emerged from scanning?
4. **Plan depth**: Which sources warrant detailed extraction?

## Anti-Patterns

| Anti-Pattern | Consequence |
|--------------|-------------|
| **Premature depth** | Reading first source exhaustively before scanning others; misses broader context |
| **Query tunnel vision** | Using only one query formulation; misses alternative framings |
| **Source monoculture** | Scanning only one source type; misses complementary perspectives |
| **Infinite scanning** | Never transitioning from broad scan to focused investigation; delays analysis |

## Saturation Signal

Scanning is complete when new queries return familiar results. Saturation indicates the landscape is mapped. This does not mean every source has been read—only that the topology of the field is understood.

## Transition to Focused Investigation

After broad scanning, transition to:

- **Focused queries** targeting identified gaps or debates
- **Deep extraction** from prioritized sources
- **Source evaluation** of key materials

The broad scan informs all subsequent phases by establishing what exists, what matters, and what remains unknown.
