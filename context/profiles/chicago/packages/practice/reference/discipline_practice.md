# Chicago 17 Practice in This Profile

The `chicago` profile serves history and general scholarship in both
of Chicago 17's systems. It extends the module core and adds one
package, `practice`, whose two rules carry the format-family level of
each system: the notes-bibliography face, numbered notes in
first-appearance order with an alphabetical bibliography, and the
author-date face, author-year pairs with an alphabetical reference
list.

## Verifying the variant

Because one manual serves two systems, the profile's central practice
is verification before drafting. The venue's author instructions are
checked for the named system, and doubtful cases fall to the
benchmark: ten to fifteen recent publications from the venue, their
in-text shapes recorded, the pattern read off the set. The benchmark
is the core package's `Benchmark Before Choosing` rule. The Chicago
vocabulary helps the read: notes and bibliography name the
notes-bibliography system; reference list and name-date name
author-date.

## Navigating the module

Style selection across the four disciplines, and the deferred-pipeline
posture for carried citation styles and locales, are taught once in
the core package: the `Style Selection Across the Disciplines` and
`Style and Locale Assets` references there. Entry-level metadata
completeness is the same floor in both systems and is restated with
each list shape in the two rules.
