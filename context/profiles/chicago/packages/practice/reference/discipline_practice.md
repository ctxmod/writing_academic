# Chicago 18 Practice in This Profile

The `chicago` profile serves history and general scholarship in both
of Chicago 18's systems. It extends the module core and adds one
package, `practice`, whose two rules carry the format-family level of
each system: the notes-bibliography face, numbered notes in
first-appearance order with an alphabetical bibliography, and the
author-date face, author-year pairs with an alphabetical reference
list.

## Verifying the variant

Because one manual serves two systems, the profile's central practice
is verification before drafting. The venue's author instructions are
checked for the named system, and doubtful cases fall to the
benchmark: ten to fifteen recent publications from the venue, their
in-text shapes recorded, the pattern read off the set. The benchmark
is the core package's `Benchmark Before Choosing` rule. The Chicago
vocabulary helps the read: notes and bibliography name the
notes-bibliography system; reference list and name-date name
author-date.

## Navigating the module

Style selection across the four disciplines, and the deferred-pipeline
posture for carried citation styles and locales, are taught once in
the core package: the `Style Selection Across the Disciplines` and
`Style and Locale Assets` references there. Entry-level metadata
completeness is the same floor in both systems and is restated with
each list shape in the two rules.

## What changed in the 18th edition

The 18th edition (2024) replaces the 17th (2017). Its changes to
source citation that matter at this profile's level, with the
manual's paragraph numbers:

- Repeat citations: shortened notes are preferred to "ibid.", in an
  author-title, author-only, or title-only form (13.37).
- "et al.": a note or an author-date text citation names up to two
  authors, and for more than two gives the first author and "et al.";
  a bibliography or reference list names up to six, and for more than
  six gives the first three and "et al." (13.23, 13.107).
- Repeated names: a bibliography or reference list repeats the
  author's name for each entry instead of using the 3-em dash (13.72,
  13.113).
- Books: the place of publication is no longer required (14.30); a
  chapter's page range in an edited book is no longer required in the
  closing list (14.8).
- Links: expanded guidance on URLs and shortened URLs (13.11) and on
  sources archived through the Wayback Machine or a similar service
  (14.104).
- AI-generated content: new guidance on citing it (14.112) and on the
  author's duty to state whether and how far AI was used (4.51, 4.76);
  the three styles' treatments sit side by side in the core package's
  `Citing AI-Generated Content` reference.
- Terminology: "headline style" and "sentence style" are renamed
  "title case" and "sentence case" (8.159, 8.160).

CSL style files track the edition by name: in the upstream CSL
repository, `chicago-author-date.csl`, `chicago-notes-bibliography.csl`
and `chicago-shortened-notes-bibliography.csl` carry the 18th edition,
and the 17th-edition files carry a `-17th-edition` suffix. Check which
file a build uses before assuming the rendered notes follow Chicago 18.
