# APA 7 submission benchmark

A submission-time check for APA 7 manuscripts: sample ten to fifteen recent
publications from the target journal, record each one's in-text shape
(author, year, page for quotations) and the closing reference list's
ordering, and confirm the manuscript matches the stable pattern rather than
a single paper's variant.

This note belongs to the APA practice package, which is dormant under the
core profile: it becomes available only when the APA profile is selected.
