# Benchmark Before Choosing

When the target venue's citation style is uncertain, resolve it in a
fixed order before drafting: venue guidelines first, because the author
instructions name the style or link it; then disciplinary convention,
because the field's dominant style is the fallback; then the
footnote-versus-author-date check, because a venue may follow a
discipline's style while requiring its other system, as any style with
two systems allows. Never infer the style from a single sample paper.
Venues change their guidance, and one paper's practice may be a
author's habit or a production error.

## The benchmark

The check that settles a doubtful choice is a count, not an impression.
Gather ten to fifteen recent publications from the target venue and
record, for each, the in-text shape and the closing list's name and
ordering. The pattern across the set is the venue's operative
convention. A stable pattern across a full issue is the venue's
requirement; a single paper's variant is noise.

Commit the style only after the benchmark agrees with the written
guidelines. When they disagree, ask the venue. Silent selection is
precisely the error the benchmark exists to prevent, and a style
discovered after drafting is the mixed-style drift the `Hold One Style`
rule describes.
