# The Numbered In-Text Shape

In the IEEE family, the in-text citation is a number in square
brackets: `[3]` for a single source, `[3], [7]` for two, and
`[3], [7], [12]` where a claim rests on several works. A run of
consecutive numbers is written out, `[1], [2], [3], [4]`, never
`[1]–[4]`: the IEEE Reference Guide (version 3.28.2025) retired the
en-dash range. The number
identifies the work through the numbered reference list, where each
entry stands under its number. The bracketed number is the family's
whole in-text shape: no author and no year travel inside the citation.

## The number's meaning in the style's convention

In the style's convention for typeset documents, reference-list
entries are numbered in the order their works are first cited, so the
list doubles as a reading-order index, and a number never repeats for
a second citation of the same work: the same bracketed number returns
each time. Locators ride inside the brackets, `[3, p. 5]` or `[3, Fig. 1]`, and
replace "ibid." and "op. cit.", which the style eliminates. When the
text names authors, three or more become the first author and "et
al." (`Wood et al. [7]`).

This is the style manual's convention, not a claim about ctxmod's
rendering. The tool's own citation rendering is a fixed posture,
named markers over a name-sorted footnotes list, that no style's
numbering convention changes.
